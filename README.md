# INGESA · pruebas de barra superior

Repo solo para probar en el navegador las variantes de la barra superior del portal INGESA v4.5. No es el portal de producción (ingesa.oneapp.dev).

- `v6a/index.html` — Variante A · Pro de escritorio (vidrio oscuro).
- `v6b/index.html` — Variante B · Píldora flotante rosa premium.
- `v5.2/index.html` — Base v5.2 · barra en 3 zonas, agenda en ingesa-database.

Cada carpeta es un `index.html` autocontenido. Para probar con GitHub Pages, cada variante se sirve desde su carpeta.
